## UserStories


Participant (Learner)
   1. As a participant, I want to create an account so that I can access the training portal.

   2. As a participant, I want to log in securely so that my account stays protected.

   3. As a participant, I want to browse available trainings so that I can choose what to enroll in.

   4. As a participant, I want to search and filter trainings so that I can find the right one quickly.

   5. As a participant, I want to view training details (overview, schedule, instructor) so that I know what I’m enrolling into.

   6. As a participant, I want to enroll in a training program so that I can attend.

   7. As a participant, I want to cancel my enrollment so that I’m not locked into a training I can’t attend.

    8. As a participant, I want to see my enrolled training so that I can track what I signed up for.

    9. As a participant, I want to see my completion status so that I can prove I finished the training.

    10. As a participant, I want to download a completion certificate so that I can share it with my manager/HR.

Instructor

   11. As an instructor, I want to create training so that I can publish a learning program.

   12. As an instructor, I want to edit training details so that the information stays accurate.

   13. As an instructor, I want to publish/unpublish training so that only ready training is visible.

   14. As an instructor, I want to see the roster of enrolled participants so that I can manage attendance.

   15. As an instructor, I want to mark attendance so that participation is recorded.

   16. As an instructor, I want to mark completion so that participants receive credit.

Admin

   17. As an admin, I want to manage user accounts so that I can control access.

   18. As an admin, I want to assign roles (participant/instructor/admin) so that permissions are correct.

   19. As an admin, I want to approve training before publishing so that quality standards are maintained.

   20. As an admin, I want to generate a roster report so that I can provide enrollment documentation.

   21. As an admin, I want to generate a completion report so that I can submit proof to stakeholders.

   22. As an admin, I want to view system activity logs so that security and accountability are maintained.
