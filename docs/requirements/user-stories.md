## User Stories

# 1. Student User Stories

1. As a student, I want to register an account so that I can access the training portal.
2. As a student, I want to log in securely so that my data remains protected.
3. As a student, I want to browse available courses so that I can choose relevant training.
4. As a student, I want to enroll in a course so that I can begin learning.
5. As a student, I want to view my course progress so that I can track completion.
6. As a student, I want to see my grades so that I understand my performance.

# 2. Instructor User Stories

1. As an instructor, I want to create new courses so that I can provide training programs.
2. As an instructor, I want to upload course materials so that students can access learning resources.
3. As an instructor, I want to record grades so that student performance is documented.
4. As an instructor, I want to view enrolled students so that I can manage participation.

# 3. Admin User Stories

1. As an admin, I want to manage user accounts so that I can control system access.
2. As an admin, I want to approve course listings so that quality standards are maintained.
3. As an admin, I want to generate reports so that I can analyze institutional performance.
4. As an admin, I want to monitor system activity so that security is maintained.
